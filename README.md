# SkillBridge — Frontend Demo

A responsive LMS-style student dashboard built with HTML, CSS, and JavaScript, served locally with Vite.

## Requirements

- Node.js 18 or newer
- npm (included with Node.js)

## Run in VS Code or another IDE

1. Clone or download this repository.
2. Open the project folder in VS Code (or your preferred IDE).
3. Open the integrated terminal in the project folder.
4. Install dependencies:

   ```bash
   npm install
   ```

5. Start the local development server:

   ```bash
   npm run dev
   ```

6. Open the local URL printed in the terminal (usually http://localhost:5173).

## Other commands

```bash
npm run build    # Create a production build in dist/
npm run preview  # Preview the production build locally
```

## Included

- Student overview and learning statistics
- Course browsing and live search
- Assignment list and demo actions
- Learning progress view
- Responsive navigation and layouts

## Demo-only behaviour

All course, learner, assignment, and progress details are sample data. Interactions are local presentation behaviours only. There is no login, authentication, API, database, server, or credential requirement. No environment variables are needed.

This repository intentionally contains only the frontend demo.
