# SkillBridge — Frontend Demo

A standalone, responsive LMS-style student dashboard built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in any modern browser. No build step, package installation, server, environment variables, or backend is required.

## Included
- Student overview and learning statistics
- Course browsing and live search
- Assignment list and demo actions
- Learning progress view
- Responsive navigation and layouts

## Demo-only behaviour
All course, learner, assignment, and progress details are sample data. Interactions are local presentation behaviours only. There is no login, authentication, API, database, server, or credential requirement.

This repository intentionally contains only the frontend demo.
